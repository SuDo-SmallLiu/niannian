## 用户路径（当前可用）

```
登录 → 创建/加入家庭
    ↓
上传照片 → AI 解析记忆卡 → 补充细节（可选）
    ↓
发现故事（3–5 个 Story）→ 故事库 H5 播放
    ↓
生成人生电影 → 沉浸式 MP4 / 互动 H5
    ↓
分享海报 / 微信保存
```

**念念 Agent 5 步：** 上传 → 解析 → 补充 → 故事 → 电影
